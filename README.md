# KiCad-Userlibs: 3D-Modelle

Eigene und von Herstellern stammende 3D-Modelle (u. a. STEP, STP, M3D) für KiCad-Footprints.

## Verwendung

Das Repository wird in KiCad über die Pfadvariable `THE78MOLE_LIBS` eingebunden, z. B. `${THE78MOLE_LIBS}/3dmodels`.
`THE78MOLE_LIBS` zeigt auf das Verzeichnis, in dem dieses Repository als Unterordner `3dmodels` liegt.
